# LATITUDE 営業時間の書き方（open）

作成: 2026-11-15 ／ 読む人: 店の営業時間を調べて、データに入れる人

店のデータ（`lib/latitude-places/<町>.json`）の1軒ごとに、決まった時間割 `open` を書ける。
書くと、店のカードに「いまは時間割では営業時間内か」が小さく出る。

## 1. まず守ること

1. **店の公式の情報だけ**（店のサイト、公式の Instagram など）。まとめサイト・地図アプリ・口コミは使わない。
2. **推測しない**。はっきり書いていない所は書かない。分からない店は `open` を書かない（何も出ないだけで、困らない）。
3. **`checked`（確かめた日）と `source`（確かめたページの URL）は必ず書く**。無いと検査で落ちる。
4. 書いたら `node scripts/latitude-open-check.mjs` を流す（問題が0になるまで直す）。

## 2. 形

```json
"open": {
  "week": {
    "mon": [],
    "tue": [["10:00", "17:00"]],
    "wed": [["10:00", "17:00"]],
    "thu": [["10:00", "17:00"]],
    "fri": [["10:00", "17:00"]],
    "sat": [["11:00", "14:00"], ["17:00", "21:00"]],
    "sun": [["11:00", "14:00"], ["17:00", "21:00"]]
  },
  "holiday": "shift",
  "irregular": false,
  "note": { "ja": "L.O. 13:30、20:30", "en": "Last order 13:30, 20:30" },
  "checked": "2026-11-15",
  "source": "https://example.jp/access"
}
```

| 項目 | 書き方 |
|---|---|
| `week` | **7つの曜日を全部**（`mon` `tue` `wed` `thu` `fri` `sat` `sun`）。定休日は `[]`。昼と夜で分かれる店は範囲を2つ、早い順に。 |
| 時刻 | `"HH:MM"`（`"09:30"`。頭の0を付ける）。閉まる時刻が開く時刻と同じか前なら、夜中の0時を越える（`["18:00","01:00"]`）。`"24:00"` も使える。 |
| `holiday` | 日本の祝日の扱い。`"open"`＝祝日も、その曜日の時間で営業（定休日が祝日でも営業）／`"closed"`＝祝日は休み／`"shift"`＝定休日が祝日なら営業し、次の平日が休み。**書いていなければ付けない**。 |
| `irregular` | 店が自分で「不定休」と書いている時だけ `true`。 |
| `note` | 短い補足（日本語と英語の両方）。L.O.、売り切れ次第終了、季節の違いなど。 |
| `checked` | 確かめた日 `YYYY-MM-DD`。 |
| `source` | 確かめた公式のページの URL。 |

前からある字の項目 `hours` / `closed`（「10:00–17:00」「水曜」）はそのまま残す。
字があればサイトはその字を出し、無い時だけ `week` から字を作る（例「10:00–17:00 · 休み：月曜」「平日 11:00–15:00、土日 10:00–17:00」）。
`note` が出るのは、`week` から字を作った時だけ（手で書いた字には足さない）。

## 3. よくある形

| 店のサイトの書き方 | 書き方 |
|---|---|
| 10:00〜17:00 月曜定休 | 月は `[]`、ほかは `[["10:00","17:00"]]` |
| 月曜定休（祝日の場合は翌日） | 月は `[]`、`"holiday": "shift"` |
| 水曜定休（祝日は営業） | 水は `[]`、`"holiday": "open"` |
| 日曜・祝日休み | 日は `[]`、`"holiday": "closed"` |
| 不定休 | `"irregular": true`（`week` は決まった時間を書く） |
| ランチ 11:30〜14:00／ディナー 17:30〜21:00 | 1日に2つ: `[["11:30","14:00"],["17:30","21:00"]]` |
| 〜21:00（L.O. 20:30） | **閉まる時刻（21:00）を書く**。L.O. は `note` に |
| 売り切れ次第終了 | 書いてある閉まる時刻を書き、`note` に「なくなり次第終了」 |
| 夏は〜18:00、冬は〜17:00 | **いまの季節**の時間を `week` に、ほかの季節は `note` に。季節が変わったら書き直す |
| 予約のみ（予約すれば開く） | `open` は書かない。`"reserve": "required"` |
| 「ご予約の方のみ」「お問い合わせください」「時間未定」 | `open` を書かない |

## 4. サイトで何が出るか

カードの営業時間の行の下に、1行だけ出る。**「営業中」とは言わない**（臨時休業は分からないので）。

| いつ | 出る字 |
|---|---|
| 時間割の中 | 営業時間内 · 17:30まで ／ Usually open now · until 17:30 |
| 閉まるまで30分以内 | まもなく終了 · 17:30まで |
| 今日はこれから・もう終わった | 営業時間外 · 本日17:00から ／ 明日9:00から ／ 水曜9:00から |
| 定休日 | 本日は定休日 · 次は水曜9:00から |
| `irregular: true` | 不定休あり（状態は出さない） |

時刻は**その町の時刻**（日本の町は日本時間。見る人の時計ではない）。
営業時間の行の終わりに、小さく「2026年11月確認」と出る。カードの「行く前に公式サイトで確かめてください」の1行と Google マップのボタンはそのまま。

**わざと出さない時**（安全のため。何も出さないか、注意の1行だけ）

- `checked` が無い、または12か月より前 → 出さない（確かめ直す）
- 年末年始（12/29〜1/3） → 「年末年始は営業時間が変わることがあります」
- 日本の祝日で `holiday` が無い → 「祝日は営業時間が変わることがあります」
- `holiday: "shift"` で、今日か昨日が祝日 → 同じ注意（どの日が休みか、ずらして当てない）
- `holiday: "open"` で、その日が定休日の曜日 → 同じ注意（その日の時間が分からない）
- 祝日の表に無い年（いまは 2026・2027年まで。`lib/latitude-open.ts`） → 出さない
- 日本の外の町は、祝日を見ない（曜日の時間割だけ）

## 5. 調べた字から open を作る

調べる人は、まず字で書く（`hours` / `closed`）。入力はここ（読むだけ。別の作業の物）:

- `~/Desktop/vault.vual.jp/docs/latitude-shop-hours/VERIFIED.json` … 写した文（引用）がその店のページに本当にあるかを機械で確かめた後の物。**これを使う**
- `~/Desktop/vault.vual.jp/docs/latitude-shop-hours/raw/OUT-*.json` … 確かめる前の物（同じ中身、項目名が `hoursJa` などで少し違う）

字の書き方（調べる人の決まり）: 時刻は `10:00–18:00`（日本語でも en dash）、昼と夜は `、`、曜日で違う時は `平日 11:00–15:00、土日 10:00–17:00`、L.O. は `（L.O. 17:30）`、休みは `水曜（祝日は営業）` `不定休` `無休`。

### 対応表（実際の字から）

| 字（hours ／ closed） | open |
|---|---|
| `9:00–18:00` ／ `無休（元日を除く）` | 7日とも 9:00–18:00。元日は年末年始の決まりで出ないので、そのまま。`note`「元日は休み」 |
| `平日 10:00–17:30、土日 10:00–19:30` ／ `不定休` | 月〜金と土日を分けて書き、`irregular: true` |
| `8:00–18:45` ／ `月曜・火曜・水曜` | 月火水は `[]`、木〜日 8:00–18:45 |
| `10:00–18:00` ／ `水曜（祝日は営業）` | 水は `[]`、`holiday: "open"` |
| `11:30–14:00（L.O. 13:45）、17:30–21:00（L.O. 20:30）` ／ `月曜` | 1日に2つ。`note`「L.O. 13:45、20:30」 |
| `9:00–17:00` ／ `火曜（祝日の場合は翌日）` | 火は `[]`、`holiday: "shift"` |
| `10:00–17:00` ／ `日曜・祝日` | 日は `[]`、`holiday: "closed"` |
| `10:00–16:00` ／ `無休（臨時休業あり）` | 7日とも。**不定休にしない**（下を見る） |
| `平日 11:00–15:00、土日祝 11:00–16:00（夜の部は要予約）` ／ `水曜` | **書かない**。祝日だけ別の時間（`holiday` では表せない）で、予約の夜もある |
| `3〜10月 10:00–18:00、11〜2月平日 10:00–17:30` ／ `火曜（祝日の場合は翌日）・年末年始` | **自動では書かない**。いまの季節の時間を手で `week` に、ほかを `note` に |
| `10:00–17:00` ／ `第1・第3日曜` | **書かない**（月の何週目かの休みは表せない） |
| `9:00–18:00` ／ `月曜（祝日により変動あり）・不定休` | **書かない**（決まりが書いていない） |

### irregular（不定休）の決まり

- `irregular: true` は、**店が自分で休みを「不定休」と書いている時だけ**（「不定休」「火曜・不定休」「水曜（不定休あり）」）。
- 「年中無休 ※臨時休業あり」「火曜（臨時休業あり）」は不定休**ではない**。どの店も急に休むことはある。そのためにカードの「行く前に確かめてください」の1行がある。
- 「月内に不定期で火曜休あり」「8月は不定休」のように、決まりの一部だけが不定な物は、自動では書かない（手で確かめる）。

### open を書かない（空のままにする）時

- 営業時間か休みの、どちらかが無い（字が片方だけ）
- 季節・月で時間が変わる（いまの季節を手で入れるまで）
- 「頃」「〜（終わりが無い）」「深夜」「要予約」「予約制」「お問い合わせ」
- 店の中で部分ごとに時間が違う（「店舗 10:00–17:00、カフェ …」）
- 祝日だけ別の時間、祝前日だけ別の時間
- 第1・第3など、月の何週目かの休み
- 祝日の決まりがはっきりしない（「祝日により変動」「祝日は原則営業」「大安を除く」）

### 変換スクリプト

`scripts/latitude-open-from-text.mjs` が、上の対応表のうち**全部読める店だけ**、`open` の案を作る（厳しく作る。少しでも読み残しがあれば出さない）。

```bash
node scripts/latitude-open-from-text.mjs --checked 2026-11-14 --out /tmp/open-proposals.json --skipped /tmp/open-skipped.json \
  ~/Desktop/vault.vual.jp/docs/latitude-shop-hours/VERIFIED.json
node scripts/latitude-open-check.mjs --file /tmp/open-proposals.json
```

- 時刻と休みの曜日が、写した引用（`quoteHours` / `quoteClosed`）に本当にあるかも確かめる。無ければ出さない。
- 祝日の決まりは、書いてある時だけ付ける。
- **データ（`lib/latitude-places/*.json`）には書かない**。案を目で確かめてから、別の作業でデータに入れる。
- 読めなかった店は `--skipped` のファイルに理由つきで出る。手で入れるか、空のままにする。

## 6. 検査

```bash
node scripts/latitude-open-check.mjs              # データ全部
node scripts/latitude-open-check.mjs --file x.json  # 案のファイル
```

曜日がそろっているか、時刻の形、範囲の順番と重なり、`holiday` の値、`checked` と `source` を確かめる。
問題があると `町 / 店: 何が悪いか` の行が出て、終わりのコードが 1 になる。最後に、`open` のある店の数（町ごと）が出る。
